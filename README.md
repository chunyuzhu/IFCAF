# A novel implicit cross-attention framework for RGB-T object detection
## Intro
Official Code for [A novel implicit cross-attention framework for RGB-T object detection](https://www.sciencedirect.com/science/article/pii/S0957417426004835).
## Installation
Install libraries including numpy, pytorch, timm, mamba-ssm, etc. according to `requirement.txt`

## Training
```
   python train.py
```
   
## Test
```
   python val.py
```

## Visualize
```
   python result_vis.py
```
